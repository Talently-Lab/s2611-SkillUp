# 📚 Documentación General del Proyecto

Espacio centralizado para la documentación técnica, de gestión y control de calidad del proyecto **SkillUp Campus**.

## Subcarpetas
* `/api`: Contratos de API, especificaciones y colecciones exportadas de Postman.
* `/qa`: Planes de prueba, matrices de casos de uso y reportes de incidencias/bugs.
* `/pm`: Minutas de reuniones de equipo, acuerdos y cronogramas de seguimiento.
