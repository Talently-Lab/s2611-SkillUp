# 🧩 Frontend Source (src)

Contiene la implementación visual y lógica de la aplicación React:
* **Componentes:** Elementos reutilizables de UI (botones, navbar, tarjetas de cursos).
* **Páginas / Vistas:** Pantallas completas (Login, Catálogo, Detalle de Curso, Panel de Alumno, Dashboard Admin).
* **Estilos:** Configuración y clases de Tailwind CSS o CSS modular.
* **Servicios / API:** Módulos de llamada `fetch` o `axios` hacia los endpoints del backend.
