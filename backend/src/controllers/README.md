# 🎮 Controladores (controllers)

Contiene las funciones que procesan las peticiones (`req`, `res`):
* Reciben los parámetros y datos del cuerpo de la petición.
* Invocan a la capa de datos/modelos para ejecutar la lógica de negocio.
* Retornan las respuestas con los códigos de estado HTTP adecuados (`200`, `201`, `400`, `404`, etc.).
