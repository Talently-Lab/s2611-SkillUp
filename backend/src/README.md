# 🧱 Backend Source (src)

Estructura modular del servidor basada en separación de responsabilidades:
* `config/`: Conexión a base de datos y configuración global.
* `controllers/`: Manejadores de peticiones HTTP y respuestas.
* `middlewares/`: Filtros de autenticación, control de roles y validaciones.
* `models/`: Acceso y consultas a la base de datos (capa de datos).
* `routes/`: Definición de endpoints y mapeo de rutas HTTP.
