## 🛠️ Decisiones Técnicas y Stack

Para este proyecto se optó por un stack moderno, escalable y enfocado en la velocidad de entrega (MVP de 10 días):

* **Frontend:** React + Vite, Tailwind CSS (para una interfaz rápida, limpia y responsive).
* **Backend:** Node.js v24LTS + Express (arquitectura de API REST modular).
* **Base de Datos:** PostgreSQL v17 (relacional, ideal para garantizar consistencia de datos).
* **Control de Versiones y Gestión:** GitHub, Trello (Tablero Kanban para seguimiento de tareas).
* **Documentación de API:** Postman (colección exportada en `/docs/api/`).
